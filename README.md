# CGPA Management System

A console-based CGPA Management System built in C++. It helps students record their courses, grades, and credit hours, and calculates GPA and CGPA automatically.

## Features

- Add courses with grade and credit hours
- Calculate semester GPA
- Calculate overall CGPA
- View all saved records
- Update or delete a course record
- Simple menu-driven interface
